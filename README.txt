V1.46 AUTONOME

Correction importante :
La carte de France est maintenant intégrée directement dans index.html en base64.
Il n'y a plus besoin d'envoyer un dossier assets/ sur GitHub.

Pour mettre à jour le site :
1. Remplacer uniquement index.html dans le dépôt local GitHub.
2. Commit.
3. Push / synchronisation.
4. GitHub Pages republie automatiquement.

Cette correction règle le problème de carte invisible quand seul index.html était envoyé.
